이번 주(10월 19일~25일)는 OpenAI와 Anthropic의 발표가 많았습니다. 이 글에는 공식 발표나 원문을 직접 확인한 5건만 담았습니다. 원문을 확인하지 못한 소식은 뺐습니다.

1. **ChatGPT 광고, 26개국 추가**
   - **요약:** OpenAI가 10월 21일 ChatGPT 광고를 26개 국가에 추가했다고 발표했습니다. 광고주는 10만 명을 넘었다고 밝혔습니다. 광고는 무료와 Go 요금제에만 노출되고, Plus·Pro·Enterprise는 광고가 없습니다.
   - **내 업무/수익 관점:** 광고 지면이 넓어지면서 광고주 쪽에서 ChatGPT 기반 마케팅 실험 수요가 늘어날 수 있습니다. 마케팅·CRM 업무와 연결해 볼 만합니다.
   - **자세히 보기:** [OpenAI 발표](https://openai.com/index/chatgpt-ads-expands-26-new-countries/)

2. **Anthropic, 프로액티브 에이전트 앱 Claude Duet 공개**
   - **요약:** Anthropic이 10월 21일 Claude Duet을 연구 프리뷰로 공개했습니다. 사용자가 맡긴 작업을 수행하고, 자리를 비운 사이에도 백그라운드에서 계속 작업합니다. 메시지 발송, 결제, 파일 삭제처럼 중요한 행동 전에는 사용자에게 확인을 요청합니다. 현재는 미국 Pro·Max 요금제 대상 대기자 명단 방식입니다.
   - **내 업무/수익 관점:** 업무 보조 에이전트를 직접 써 볼 수 있는 단계라서, 반복 업무에 어떻게 쓸지 테스트해 볼 만합니다.
   - **자세히 보기:** [Claude Duet 소개](https://claude.com/resources/articles/claude-duet)

3. **Anthropic, Agent Skills를 Agentic AI Foundation에 기증**
   - **요약:** 10월 22일 Anthropic은 에이전트에 전문 지식과 작업 절차를 전달하는 개방형 표준 'Agent Skills'를 Linux Foundation 산하 Agentic AI Foundation(AAIF)에 기증한다고 발표했습니다. 발표 시점에 70개가 넘는 에이전트 플랫폼이 이 표준을 지원했고, 글에서는 ChatGPT, Cursor, GitHub Copilot, VS Code가 언급됐습니다.
   - **내 업무/수익 관점:** 한 번 만든 업무 절차를 여러 도구에서 재사용할 수 있는 방향이라, 업무 자동화 설계에 참고할 만합니다.
   - **자세히 보기:** [Anthropic 발표문](https://www.anthropic.com/news/donating-agent-skills-to-the-agentic-ai-foundation)

4. **OpenAI, 신약 개발 스타트업 Orchestra Bio 인수**
   - **요약:** 10월 20일 OpenAI가 샌프란시스코의 신약 개발 소프트웨어 스타트업 Orchestra Bio를 인수했다고 발표했습니다. 이 회사의 에이전트는 임상시험 일정 조율과 예산 관리 같은 운영 업무를 맡습니다. 인수 금액은 공개되지 않았고, 팀과 기술은 OpenAI의 생명과학 모델 Rosalind에 합쳐질 예정입니다.
   - **내 업무/수익 관점:** 전문 분야 업무 에이전트를 인수해 붙이는 흐름이 강해지고 있습니다. 특정 산업에 특화된 에이전트 시장이 커진다는 신호로 볼 수 있습니다.
   - **자세히 보기:** [OpenAI 인수 발표](https://openai.com/index/openai-to-acquire-orchestra-bio/)

5. **Uber, ChatGPT Work를 직원 약 3만 명에게 확대**
   - **요약:** 10월 22일 Uber는 ChatGPT Work를 전 세계 직원 약 3만 명에게 배포한다고 밝혔습니다. 7월부터 진행한 1,000명 규모의 시범 운영을 확대한 것입니다. 보도에 따르면 시범 참여자의 약 80%가 개발자가 아닌 직군이었습니다.
   - **내 업무/수익 관점:** 개발팀이 아닌 직군에서 업무 에이전트를 쓰는 사례라서, 실무 적용을 검토할 때 참고할 만합니다.
   - **자세히 보기:** [Unite.AI 보도](https://www.unite.ai/uber-rolls-out-chatgpt-work-to-more-than-30-000-employees/)

## 이번 주 체크포인트

- 광고와 업무 에이전트가 동시에 확장되며 OpenAI의 수익화 방향이 뚜렷해지고 있습니다.
- 개인이 쓸 수 있는 업무 에이전트(Claude Duet)가 늘고 있어 직접 테스트해 볼 시점입니다.
- 다음 주에는 Agent Skills 표준의 진행 상황을 확인하겠습니다.
